# Better Comments Settings

## 📌 Commenting Conventions

This project uses the **Better Comments** extension in VS Code to highlight different types of annotations in the code.  
The following table shows all configured tags:

| Tag          | Color      | Style               | Meaning |
|--------------|------------|---------------------|---------|
| **BUG**      | 🔴 Red (#FF3333) | **Bold** | Indicates a bug in the code that must be fixed |
| **FIXME**    | 🟠 Orange (#FF6600) | **Bold** | Faulty code that should be corrected |
| *HACK*       | 🟡 Yellow (#FFCC00) | *Italic* | Temporary or hacky solution |
| DEBUG        | 🔵 Blue (#66AADD) | Underlined | Debugging information |
| TRACE        | 🟣 Purple (#BD93F9) | Normal | Detailed trace information |
| **TODO**     | 🟡 Yellow (#FFFF55) | **Bold** | Pending task to be implemented |
| OPTIMIZE     | 🟢 Green (#33DD88) | Underlined | Code that could be optimized |
| **REFACTOR** | 🟢 Green (#33CC66) | **Bold** | Code that needs restructuring |
| ~~CLEANUP~~  | ⚪ Gray (#BBBBBB) | ~~Strikethrough~~ | Code that should be cleaned/removed |
| **REVIEW**   | 🔵 Blue (#44AAFF) | **Bold** | Code section that should be reviewed |
| **SECURITY** | 🔴 Dark Red (#CC0000) | **Bold** | Security-critical section |
| PERFORMANCE  | 🟢 Green (#22BB66) | Underlined | Performance-related concern |
| SCALABILITY  | 🟢 Green (#228855) | Normal | Scalability-related concern |
| *COMPATIBILITY* | 🟣 Purple (#9966FF) | *Italic* | Compatibility issues |
| DEPENDENCY   | 🟤 Yellow (#DDCC77) | Normal | External or internal dependency |
| ~~DEPRECATED~~ | ⚪ Gray (#999999) | ~~Strikethrough~~ | Deprecated code to avoid |
| ~~LEGACY~~   | ⚪ Gray (#CCCCCC) | ~~Strikethrough~~ | Old legacy code |
| NOTE         | 🔵 Light Blue (#57C7FF) | Normal | Informative note |
| **WARNING**  | 🟠 Orange (#FFAA00) | **Bold** | Important warning |
| *QUESTION*   | 🔵 Light Blue (#8BE9FD) | *Italic* | Raised question or doubt |
| IDEA         | 🟠 Orange (#FFAA44) | Underlined | Suggestion or improvement idea |
| ~~WTF~~      | 💖 Pink (#FF00AA) | ~~Strikethrough~~ | Something confusing or weird |
